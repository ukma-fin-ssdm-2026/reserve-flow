# Матриця простежуваності вимог (RTM)

Ланцюг: **бізнес-потреба** (`Project-Description.md`) → **користувацька історія** (`user-stories.md`) → **системна вимога FR / NFR** (`requirements.md`) → **код** (з'явиться в наступних лабораторних) → **тести**.

Позначення тестів: `TC-###` — функціональний тест, `PT-###` — тест продуктивності, `ST-###` — тест безпеки, `RT-###` — тест надійності (конкурентності).

Статуси: `Планується` → `Розробка` → `Реалізовано` → `Перевірено`.
